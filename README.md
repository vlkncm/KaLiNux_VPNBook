# VPNBook Kali — Kurulum ve Kullanım

1. [VPNBook-Kali-v2.zip](VPNBook-Kali-v2.zip) dosyasını indirin ve çıkarın. `Kur.sh` dosyasının bulunduğu klasörde terminal açın.
2. Kurulumu başlatın:

   ```bash
   bash Kur.sh
   ```

3. İstendiğinde Kali kullanıcı parolanızı girin. Kurulum bitince uygulamalar menüsünden **VPNBook Kali**’yi açın.
4. VPNBook sayfasından sunucu ve protokol seçerek `.ovpn` dosyalarını indirin. ZIP olarak indiyse önce çıkarın.
5. Programda **OVPN dosyası ekle** düğmesiyle profilleri yükleyin.
6. Aynı web sayfasındaki güncel VPN kullanıcı adı ve şifresini programa girip **Bağlan**’a basın.
7. Bir profil bağlanamazsa diğer eklediğiniz profiller otomatik denenir. VPN’i kapatmak için **Bağlantıyı kes** düğmesini kullanın; pencereyi kapatmak bağlantıyı kesmez.
